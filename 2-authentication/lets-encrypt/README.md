# Let's encryptとは

以下、Geminiの回答

Let's Encryptとは、非営利団体ISRGが提供する、無料、自動化、オープンなSSL/TLS証明書の発行サービスです。すべてのウェブサイトを暗号化して安全にすることを目的にしています。

https://letsencrypt.org/ja/about/

世界中の無料かつ自動化されたSSL/TLS証明書発行サービスにおいて、Let's Encryptが圧倒的に一番有名で、最も広く使われています。

なぜ一番有名なのか？

圧倒的なシェア：世界全体の全ウェブサイトの約半数以上、無料証明書市場においては実質的なデファクトスタンダード（業界標準）となっています。

強力なスポンサー：Mozilla、Google、Cisco、Metaなど、インターネットの基盤を支える超大手企業や団体がバックアップしています。

高い信頼性：ほぼすべての主要なブラウザ（Chrome, Safari, Edgeなど）やスマートフォンに標準で信頼された認証局として組み込まれています。
