以下を実現するコード一式(docker-compose.yml)を出力してください。

DockerコンテナA, B, Cを用意します。
AとCの間の通信は必ずBを経由します。

Aはdnsキャッシュサーバ1であり、example1.testのAレコードを持っています。AレコードのIPアドレスはです。
Bはプロキシサーバのような役割をしています。
Cはdnsキャッシュサーバ2であり、問い合わせが来たら、Aに問い合わせます。

やりたいことは以下の通り。

- BからCに対して、digコマンドで「example1.test」の名前解決を行います。
- するとCからAに（Bを経由して）dnsの問い合わせを行います。
- この時にAは、返却まで10秒遅延させます。
- その間に、BがAのフリをしてCに問い合わせの結果を返します。ただし、AレコードのIPアドレスは、固定値1.2.3.4とします。
