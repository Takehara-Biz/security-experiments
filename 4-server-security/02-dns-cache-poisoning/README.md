以下を実現するプログラムです。

DockerコンテナA, B, C, Dを用意します。
AとCの間の通信は必ずBを経由します。

AはDNSコンテンツサーバであり、example1.testのAレコードを持っています。
Bはプロキシサーバの役割をしています。
CはDNSキャッシュサーバであり、Cに名前解決の問い合わせが来たら、Aに問い合わせます。
Dはクライアントであり、Cに名前解決の問い合わせを行います。

やりたいことは以下の通りです。

- DからCに対して、digコマンドで「example1.test」の名前解決を行います。
- するとCからAに（Bを経由して）dnsの問い合わせを行います。
- この時にAは、応答まで一定時間遅延させます。
- その間に、BがAのフリをしてCに問い合わせの結果を返します。ただし、AレコードのIPアドレスは、固定値1.2.3.4（不正なIPアドレス）になっています。
- Dのコンソール上には、不正なIPアドレスが表示されます。
